# Spreadsheet surface

The standalone editor uses Univer Sheets OSS 1.2.0 (`@univerjs/presets`,
`@univerjs/preset-sheets-core`), copyright DreamNum, Apache License 2.0.
https://github.com/dream-num/univer/blob/dev/LICENSE

Only local OSS rendering/interaction packages are used. XLSX import/export,
formula execution and source persistence are owned by Node BI's backend adapter.
No Univer Pro service, account, commercial import/export module or cloud upload is used.
Native SDK controls use Russian for the Tatar locale; Node BI controls retain RU/EN/TT.
