# Проверка удобства: от книги до дашборда

Дата: 24 сентября 2026. Проверка разработчиком и автоматизированными сценариями,
без испытаний с экономистами. Это проверка конкретных задач, а не полная сертификация доступности.

## Найдено и исправлено

| Препятствие | Доказательство | Изменение |
|---|---|---|
| P2: новый график выдавал ошибку ещё до выбора полей | Browser-тест до исправления зарегистрировал один запрос preview при пустых обязательных полях | Подсказки о недостающих полях; preview и применение ждут заполнения |
| P2: выбор и порядок столбцов таблицы были разными дублирующими списками | Проверка формы и исходного компонента | Один упорядоченный список, поиск, счётчик, стрелки; недоступное поле можно убрать |
| P2: удаление книги вложено в кнопку выбора и недоступно с клавиатуры; загрузчик скрыт через display:none | Проверка DOM; после исправления browser-сценарий Enter/filechooser и отмена удаления | Отдельная настоящая кнопка удаления, доступный input загрузки, видимый фокус |
| P2: после загрузки не обозначен следующий шаг | Проверка страницы источников | Переход к расчётам и короткое объяснение работы с листом |
| P3: старт проекта предлагает четыре равнозначных технических раздела | Проверка страницы проекта | Три этапа: данные → расчёт → дашборд; библиотека визуализаций остаётся отдельной ссылкой |
| P3: пустой поиск не объясняет отсутствие результатов | Проверка библиотеки | Состояние «ничего не найдено» и очистка поиска |
| P3: две отмены раскладки и вкладки без стрелочной навигации | Проверка toolbar и tablist | Одна история отмены на дашборде; стрелки, Home/End и связь с панелью |

Назначение типов диаграмм объясняется рядом с выбором. Для скаляра поясняется,
почему табличные операции недоступны. Повторный выбор того же файла снова запускает загрузку.
Подсказки и новые действия переведены на русский, английский и татарский.

## Границы решений

Проверка заполненности формы не заменяет серверную проверку типов и результатов.
Никакие суммы, соединения или значения полей не угадываются интерфейсом.
Подготовка данных остаётся в графе, визуализация использует опубликованный результат.
Ссылки публикаций, вычисления, API и сохранённые документы не преобразуются.

## Приёмка

- Unit/component: заполненность диаграмм, удалённые поля, скаляр, дополнительные серии,
  выбор и перемещение столбца при активном поиске; существующие тесты редактора и локализации.
- Browser: доступная загрузка, отмена удаления книги, подсказки вместо преждевременного
  запроса preview, настройка графика, клавиатурные вкладки, сохранение и пустой поиск.
  В этом коротком тесте публикация готовится API как fixture; это не доказательство
  сборки всего графа руками. Отдельные существующие table-authoring сценарии проходят
  Join по одному и нескольким ключам, вычисление, публикацию и дашборд через UI.
- Browser workspace: редактирование, серия, форматирование, порядок таблицы, копия,
  конфликт вкладок, перезагрузка, узкий экран, три языка и две темы.
- TypeScript, ESLint, production build. Точные результаты текущей сессии — в STATUS.md.

## Беспристрастная оценка

Работа с уже подготовленными данными стала понятнее: меньше повторяющихся элементов,
ошибка не появляется до завершения обязательного выбора, следующий шаг обозначен явно.
Это подтверждённые изменения интерфейса, но не измеренное ускорение пользователя.

Подготовка сложного графа всё ещё требует понимания ключей Join, детализации данных,
агрегаций и публикаций. Интерфейс не делает эти аналитические решения автоматически.
Для больших графов остаётся нагрузка на поиск нужной ветки; текущая проверка не измеряла
работу новичка со 168 узлами. Полный аудит screen reader и проверка всех ошибок импорта
также не входят в доказательства этой сессии.

Следующий шаг оценки: дать экономистам одинаковые задания на двух версиях интерфейса —
загрузить две книги, объединить, рассчитать показатель, опубликовать и оформить три виджета;
затем изменить столбцы таблицы и исправить ошибочный выбор поля. Фиксировать время,
успешность, ошибочные действия и обращения за помощью. Порядок версий чередовать.
До такого испытания проценты ускорения и оценки «интуитивности» в баллах не заявлять.
