# Полевой редактор: первая рабочая версия

В проекте откройте «Схема обработки» и нажмите **«Новая полевая схема»**.
Создаётся отдельная схема v2. Существующие схемы не преобразуются. Для повторного открытия
выберите новую схему и ссылку «Полевой редактор»; адрес содержит `mode=fields`.

1. Загрузите Excel в разделе источников проекта. В полевом редакторе слева раскройте книгу
   в разделе «Книги и листы». Нажмите название листа или перетащите его на холст.
   После сохранения на карточке появятся поля и типы; настройки заголовков доступны в инспекторе.
   Повторное открытие листа выбирает существующий узел, сохраняя его настройки и подключения.
   Если для листа уже есть несколько настроенных узлов, каталог показывает каждый отдельно.
   Поиск находит книги и листы, включая те, которые не вошли в первые 50 отображаемых записей.
2. Добавьте «Арифметика полей», выберите умножение. Протяните поля количества и цены
   к входам `a` и `b` либо выберите их по названиям в списках входов инспектора.
3. Добавьте «Добавить поле». Введите «Выручка», подключите исходную таблицу к `table`,
   результат умножения к `value`. У этого узла появится таблица с новым полем.
4. Добавьте «Сумма поля». Подключите таблицу из предыдущего узла и её поле «Выручка».
   Нажмите «Просмотр результата»: получится скалярная сумма.
5. Выберите вычисление и нажмите «Закрепить A», затем сумму и «Закрепить B».
   Каждый просмотр запускается своей кнопкой. Это две независимые выборки, а не сравнение
   строк один к одному. После правок предыдущие результаты скрываются как устаревшие.

Узлы можно подписывать, перемещать, удалять; связи — заменять через список входов.
Отмена/повтор восстанавливают черновик. Сохранение автоматическое, его состояние видно над
холстом. При конфликте двух вкладок текущий черновик остаётся локально; ошибка предлагает
повторить сохранение либо явно удалить черновик и загрузить серверную версию.

Кнопка «Показать весь граф» вписывает карточки в холст. Поиск полей ограничивает список:
подключённые поля остаются видимыми, остальные показываются порциями до 20 совпадений.
Для поиска подключения есть отдельное поле в инспекторе. Ошибка несовместимых строк означает,
что нужно явно соединить таблицы через Join; строки разных веток не сопоставляются по позиции.

При протягивании провода от выхода входы показывают ✓, × или ?: совместимы, несовместимы
либо ожидают актуальную схему. Причина показана рядом со входом; полный текст доступен при
наведении. Арифметика требует числового типа, логические операции — логического; преобразуйте
тип явным узлом. Окончательную проверку расчёта выполняет backend.
Нажмите название поля/выхода на карточке, чтобы выделить его явные связи и приглушить остальные.
Путь продолжается через полевые выражения и заканчивается на табличном преобразовании:
это не доказательство происхождения колонок через Join или Group By.
Кнопка **«Снять выделение пути»** или Escape снимает выделение. Выбор пути не сохраняет граф.

Чтобы собрать листы в карточку книги, выберите Excel Source и нажмите **«Объединить листы книги»**
в инспекторе. В карточку входят использованные листы того же файла; узлы составных блоков
не перемещаются. Название листа открывает его инспектор и поля. Поля подключаются обычными
проводами прямо из книги. «Свернуть книгу» оставляет видимыми подключённые поля.
Для отдельного представления нажмите **«Отделить лист»** или перетащите его название на пустое
место холста. Кнопка **«Вернуть лист в книгу»** возвращает его. ID узла, настройки и связи
сохраняются. **«Разобрать карточку книги»** показывает самостоятельные узлы листов.
Эти действия поддерживают отмену/повтор; положение книги, сворачивание и отделённые листы
восстанавливаются после перезагрузки. Поиск в книге не скрывает подключённые поля.

Параметры задаются в инспекторе. Их значения просмотра меняют схему и preview без сохранения
новой ревизии. Для источников с динамической схемой, например Pivot, смена параметра может
сделать ранее подключённое поле недоступным — это отображается как ошибка.

Пока это часть F2: интерфейс составных блоков,
меню операции при переносе поля на пустое место и приёмка большого графа ещё
не реализованы. Сохранённые составные блоки сохраняются, но показаны отдельными узлами.
Закрепления A/B действуют до закрытия страницы. Прямые полевые входы диаграмм/KPI и полный
сценарий с dashboard относятся к следующим этапам. Три языка и обе темы доступны.
