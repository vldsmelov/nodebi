# От двух книг до дашборда

1. На странице источников загрузите книги. Для знакомства можно использовать
   `fixtures/excel/join-orders.xlsx` и `join-prices.xlsx`.
2. Откройте workflow, раскройте книги в браузере книг и добавьте листы Orders и Prices.
3. Выберите Orders, нажмите «Объединить с…». Справа выберите Prices, ключи Product
   с обеих сторон. Внутреннее объединение сохраняет совпавшие записи, левое — все
   записи слева. В этой версии выбирается одна пара ключей.
4. В результате Join нажмите «Добавить вычисляемое поле». Назовите его Revenue,
   выберите Quantity × Price. Появится отдельная нода Calculated Column.
5. Запустите preview: для примера получатся Revenue 20 и 60. Новый столбец виден
   отдельным портом; общий выход таблицы содержит все исходные поля и Revenue.
6. Нажмите «Опубликовать этот выход» и задайте имя результата. Карточка результата
   появится на холсте. Её можно перемещать и переименовывать.
7. На карточке нажмите «Создать визуализацию». Для диаграммы выберите Product
   как категорию и Revenue как значение. Создайте также таблицу на том же результате.
8. На странице дашборда добавьте обе визуализации из библиотеки и сохраните размещение.

## Правила

- Форма создаёт обычные узлы и связи. Один шаг можно отменить и вернуть целиком.
- Существующие ветки не переподключаются: новый расчёт начинается от выбранной таблицы.
- Пропуски сохраняются. Для деления требуется выбрать ошибку либо пустое значение
  при нулевом знаменателе. Сложные выражения доступны в режиме «Формула».
- Повторяющиеся ключи Join создают все совпавшие пары; автоматического удаления дублей нет.
- Карточка результата отображает публикацию, не выполняет отдельный расчёт.
  Все её визуализации используют общий граф. Preview запускается по запросу.
- При конфликте сохранения форма визуализации не открывается по устаревшему графу;
  локальный черновик остаётся доступен для восстановления.
- Используемую публикацию удалить нельзя. В сообщении перечислены визуализации.
- Старые публикации получают первоначальные позиции при отображении; следующий
  обычный edit сохраняет их. Открытие проекта само по себе не меняет ревизию.

Группировка, фильтрация и преобразование типов по-прежнему доступны обычными нодами.
Их создание из заголовков таблицы не входит в этот этап. Сокращение ручных соединений
подтверждается устройством сценария; скорость работы людей пока не измерялась.
